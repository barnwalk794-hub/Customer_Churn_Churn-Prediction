# 📊 Customer Churn Prediction

> Predicting customer churn using Machine Learning ⚡

## 📌 About

This project predicts whether a customer will churn (leave) 
or stay based on their usage patterns and demographics.
Built using Logistic Regression and scikit-learn.

## 🎯 Problem Statement

Customer churn is a major problem for businesses.
This model helps identify customers who are likely to leave
so businesses can take action to retain them.

## ✨ Features

- 📂 Load and explore customer dataset
- 🔍 Data preprocessing and encoding
- 🤖 Logistic Regression model training
- 📈 Model evaluation with accuracy and confusion matrix
- 📊 Data visualization with matplotlib

## 🛠️ Tech Stack

- **Language:** Python
- **Libraries:** 
  - Pandas - Data manipulation
  - NumPy - Numerical computing
  - Matplotlib - Data visualization
  - Scikit-learn - Machine learning

## 📁 Dataset Features

| Feature | Description |
|---|---|
| Age | Customer age |
| Tenure | Months with company |
| MonthlyCharges | Monthly bill amount |
| ContractType | Type of contract |
| InternetService | Internet service type |
| SupportCalls | Number of support calls |
| Churn | Target variable (Yes/No) |

## 🚀 How to Run

1. Clone the repo:git clone https://github.com/barnwalk794-hub/customer-churn-prediction

2. Install dependencies:
pip install pandas numpy matplotlib scikit-learn

3. Add your dataset:
Place customer_churn.csv in the project folder

4. Run the script:python churn_prediction.py
## 📊 Model Performance

- **Algorithm:** Logistic Regression
- **Train/Test Split:** 80/20
- **Evaluation:** Accuracy Score + Confusion Matrix

## 📈 Visualization

- Scatter plot of Tenure vs Monthly Charges
- Shows relationship between customer tenure and charges
